# 「音痴」だと思ってた人の正体、実は筋肉のクセだった話

おとちゃん「ねえねえたろうさん、聞いてよ〜！」

たろう「お、また面白いことを企んでいる顔だね。どうしたの？」

おとちゃん「今日の体験レッスンに来てくれた方がね、開口一番『私、生まれつき音痴なんです……』って、めちゃくちゃ申し訳なさそうに言ってたんだよ🎤」

たろう「あるある〜。でもさ、これ、みんなに伝えたいんだけど——『音痴』って、実は才能がないからじゃないんだよね」

おとちゃん「えーーっ、そうなの！？ てっきり生まれ持ったセンスの話だと思ってた……」

たろう「うちでも神咲先生がいつも言ってるんだけど、音痴の正体は、表情筋・呼吸筋・喉の筋肉の『使い方のクセ』なんだよ。楽器と同じで、正しい使い方を知らないだけ」

おとちゃん「へぇ〜！ 楽器も、正しい持ち方や弾き方を知らないと変な音が出ちゃうもんね」

たろう「そうそう。だから『才能がない』んじゃなくて『まだケアの仕方を知らないだけ』。正しいケアをすれば、誰でも改善していけるんだ」

おとちゃん「それ聞いて安心する人、めちゃくちゃ多そうだね……！ ふふっ、ずっと『自分にはセンスがないから』って諦めてた人、実はもったいなかったんだ」

## うちのレッスンが「あったかい」理由

たろう「うちのレッスンが『岡山で1番あったかいボイトレ』って言ってるのも、実はここに繋がっててね」

おとちゃん「あったかさが上達の近道ってこと？」

たろう「うん。順番があるんだよ」

- 安心できる → 体がゆるむ
- 体がゆるむ → 声が出る
- 声が出る → 「自分にもできるかも」と思える
- そう思えると → 練習が続く
- 練習が続くと → ちゃんと上達する

おとちゃん「厳しくされると逆に体がガチガチになっちゃうもんね……。だからうちは、いきなり歌わせたりしないんだ」

たろう「そう。まずはおしゃべりから。今日あった出来事とか、ちょっとしたモヤモヤとか、話すだけでいい。それだけで、実は喉の力ってふっと抜けるんだよ」

おとちゃん「嬉しいなぁ、そういう場所があるって✨」

## 音痴だと思ってた人のその後

おとちゃん「そういえば、前に来てくれた生徒のTさんも、最初は音程が全然分からないって悩んでたよね」

たろう「うん。地道にトレーニングを続けて、『この音とこの音がこのくらい離れてる』っていう音程の概念に気づいてから、少しずつ音程が取れるようになっていったんだ」

おとちゃん「才能じゃなくて、気づきと積み重ねだったんだね🎵」

たろう「そういうこと。だから、もし『自分は音痴だから』って諦めてる人がいたら、伝えたいな。それ、ただ使い方を知らないだけかもしれないよ、って」

おとちゃん「みんなは、『自分には才能がないから』って諦めちゃったこと、ない〜？ もしかしたらそれ、ただのクセかもしれないよ👏」
