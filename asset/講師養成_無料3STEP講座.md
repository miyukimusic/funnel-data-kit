# 📬 無料3STEP講座（講師養成の子ページ）

> 月額1,980円サブスク・2段階ファネル（asset/ボイストレーナー養成講座_企画メモ.md「7.」参照）のうち、第1段階にあたる無料のLINE配信講座。本人指示「まずはLINE配信の3STEP講座を作っていきたい」（2026-10-23）により着手。本人より「骨子はこれでいいと思う」と確認済み

## 目的（本人が整理・2026-10-23）

1. アウトプットしない人をふるいにかける
2. アウトプット課題を通してリストの需要をヒアリングする
3. その内容（ヒアリング結果）を本講座（第2段階・月額1,980円コミュニティ）に反映してブラッシュアップする

## 構成方針

- LINE配信本文は短くまとめ、各STEPの文末に「続きを読む」ボタンで詳細コンテンツページ（別途作成予定）へ誘導する
- STEP3はアウトプット課題。返信（アウトプット）がある人のみ次段階（月額1,980円コミュニティ）へ案内し、ふるい分けと需要ヒアリングを同時に機能させる

## STEP1（配信1通目・価値観・導入）

見出し：「教える資格」なんていらない理由

```
はじめまして、Miyuki Music代表のたろうです。

このLINEを開いてくださったということは、
「歌や音楽に関わる仕事をしてみたい」
「いつか誰かに教えてみたい」
そんな気持ちが、少しでもあるんじゃないかなと思います。

先にお伝えしたいのは、
ここでいう「先生」に、プロ級の歌唱力も、音大卒の経歴も必要ないということ。

Miyuki Musicに来る生徒さんの8割は、まったくの初心者です。
必要なのは「上手く歌えること」よりも、
生徒さんの不安に寄り添える「あったかさ」。

次回は、その「あったかさ」を仕組みにしている
Miyuki Musicの指導法について、お話しします。
```

→ 文末に「続きを読む」でコンテンツページへ誘導（未作成）

## STEP2（配信2通目・差別化・権威づけ）

見出し：「岡山で1番あったかい」と言われる理由

```
Miyuki Musicが大事にしているのは、
「記録より気持ち」という考え方。

難しい専門用語や厳しい発声論ではなく、
生徒さんの不安をほぐすところから始めます。

これまで500名以上の歌・声を指導してきた教室長みゆきが、
現場で培ってきた「寄り添いメソッド」を、
これから少しずつお伝えしていく予定です。

その前に、ひとつだけ教えてください。
```

→ 文末に「続きを読む」でコンテンツページへ誘導（未作成）

## STEP3（配信3通目・アウトプット課題＝ふるい分け＋需要ヒアリング）

見出し：あなたの経験を聴かせてください

```
ここまで読んでくださって、ありがとうございます。

最後に2つだけ、質問させてください。
（このLINEにそのまま返信する形でOKです）

① あなたがこれまで「歌・声」で悩んだこと、失敗したなと思う経験があれば教えてください
② もし自分が「先生」になるとしたら、どんな先生になりたいですか？

※お返事をくださった方には、次のご案内をお送りします
```

返信（アウトプット）がある人のみ次段階（月額1,980円コミュニティ）へ案内

## 設計意図

- ①の質問で、見込み受講生がどんな悩みを抱えているかをヒアリングでき（目的2）、本講座のカリキュラムで優先的に扱うべきテーマの発見につながる（目的3）
- ②の質問で、Miyuki Musicの理念との相性確認と、受講生自身の当事者意識を高める狙いがある
- 返信がないと次に進めない設計にすることで、ふるい分け（目的1）も同時に機能させる
