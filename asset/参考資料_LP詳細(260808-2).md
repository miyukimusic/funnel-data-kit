## 1. 教室の基本コンセプト・理念
- 「岡山で1番ゆる〜いボイトレ」
- 指導方針: 「厳しくしない・怒らない・無理させない。それでもちゃんと歌が上達する」
- 「ゆるさ」が上達への最短ルートである理由（因果の連鎖）:
  1. 安心できれば体がゆるむ → 2. 体がゆるめば声が出る → 3. 「自分にもできるかも」と思える → 4. 練習が続く → 5. ちゃんと上達する
- 音痴に対する考え方: 才能の欠如ではなく、表情筋・呼吸筋・喉の筋肉といった「筋肉の使い方のクセ」。正しいケアで誰でも改善可能
- 「記録より気持ち」: 音程・リズムの正確さより「自分らしく、心地よく歌えること」を大切にする

## 2. 特徴と大手スクールとの比較
- 完全オーダーメイド＆好きな曲でレッスン（決まったカリキュラム・楽譜は使わない）
- アットホームでゆる〜い空気感（雑談から始まる）
- 料金: 体験45分×2回無料／入会金￥0〜（大手相場10,000円〜）／月謝 月1回6,000円・月2回11,000円（1回あたり約5,000円）／回数券10回50,000円／教材費・追加費用￥0
- 初月コスト比較: 大手スクール初月相場（約23,000円〜）より12,000円以上お得
- 無料駐車場完備、夜（仕事帰り）にも対応

## 3. 生徒への約束（一部）
1. 歌うタイミングは生徒自身で決定（無理に歌わせない）
2. 初回は雑談からスタート
3. 体験レッスン後の無理な勧誘・しつこい営業は一切なし
4. 駐車場無料完備
5. 生徒のペースに寄り添ったレッスン設計

## 4. レッスンの流れ（詳細版）
**通常レッスン（45分）**
- STEP1 おしゃべり（5分）——緊張をほぐす
- STEP2 ウォームアップ（10分）——ストレッチと発声練習
- STEP3 好きな曲を歌ってみる（15分）——講師が良い点・改善点を見極める
- STEP4 ワンポイントレッスン（10分）——力を抜くコツなど1つ実践伝授
- STEP5 もう一度歌ってみる＋フィードバック（5分）——その場で上達を実感

**無料体験レッスン（45分×2回）**
- 1回目: 場所・講師の雰囲気を確認する日
- 2回目: 実際のレッスン内容を体験する日（別講師選択も可能）
- 体験当日: 手ぶら来店→カウンセリング(10分)→ウォームアップ(10分)→好きな曲1曲(15分)→フィードバック(10分)
