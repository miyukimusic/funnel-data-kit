# 講師養成｜STEP3 フォーム前 音声読み上げ台本（案）

> 無料3STEP講座（asset/講師養成_無料3STEP講座.md）STEP3「あなたの経験を聴かせてください」用。STEP1・STEP2が「続きを読む→コンテンツページで音声」だったのに対し、STEP3はアウトプット課題（フォーム）への導入として、フォームの直前に短い音声メッセージを添える構成（2026-11-05・本人依頼「STEP3にも音声をつけておきたい」）。
>
> STEP1・STEP2はみゆき先生へのインタビューのため、わざとらしさを避けて「話の種」＋自然な会話の録音・編集という方針にしたが、STEP3はたろう一人の短い語りかけ（1分前後）であり、インタビューの掛け合いとは性質が異なるため、本人依頼（2026-11-05「これに関しては読み上げ台本を作ってほしい」）により逐語の読み上げ台本として用意する

## ページ構成（案）

## ページタイトル（案）
**ここまで読んでくれて、ありがとう。**

## 読み上げ台本（たろう・約1分30秒〜2分）

```
ここまで読んでくれて、ありがとうございます。

ちょっとだけ、この質問の意味を説明させてください。

1つ目は、「歌や声で悩んだこと」。
これ、実はすごく大事な質問なんです。

自分が悩んだ経験があるからこそ、
同じように悩んでいる生徒さんの気持ちに、
本当の意味で寄り添えると思っていて。
完璧な経歴より、そういう経験の方が、
教える上での力になることがあるんです。

2つ目は、「どんな先生になりたいか」。
これは、Miyuki Musicの理念との相性を
確認したいというのもあるんですけど、
それ以上に、あなた自身が今どんなことを
大事にしたいと思っているのか、
知りたくて聞いています。

正解を探すようなテストじゃないので、
身構えずに、思ったことをそのままの言葉で
書いてもらえたら嬉しいです。

書いていただいた内容は、僕とみゆきで
ちゃんと目を通して、次のご案内を
お送りさせてもらいますね。

下のフォームから、2〜3分で答えられます。
よかったら、聞かせてください。
```

## 収録メモ
- 想定尺：1分30秒〜2分程度
- 台本どおりの読み上げでOK（STEP1・STEP2と違い、インタビューの掛け合いではなく短い語りかけのため、逐語台本の方が自然に仕上がる想定）
- 言い回しの微調整（「〜です」を「〜だよ」寄りにする等）はたろう本人の話し方に合わせて自由に変更してよい
- 「簡単に／誰でも／楽して」等は使わない。フォーム回答への心理的ハードルを下げる内容ではあるが、成果保証的な表現にはしない
