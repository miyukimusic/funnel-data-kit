## 構成

### 冒頭（番組タイトル紹介の前に入れる）

```
この番組は、「岡山で一番あったかい」ボイストレーニング・ボーカル教室、Miyuki Musicの提供でお送りします。
```

この直後に、従来通りの「Okayama Challengers Talkへようこそ！」からの番組説明・ゲスト紹介が続く。

### 番組説明文の用語変更（2026-10-05・本人指示）

従来の番組説明文「視聴者であるあなたと一緒にその想いを応援して盛り上げていこう！」を「リスナーのあなたと一緒にその想いを応援して盛り上げていこう！」に変更する。

```
この番組は岡山で活動している挑戦者の過去・今・未来を紐解き、
リスナーのあなたと一緒にその想いを応援して盛り上げていこう！
というチャンネルです。
```

10〜12組目（既存公開済み）は遡及修正の対象外。13組目（ももさん）以降の新規回から適用。

### クロージング（次のバトン紹介の直後、インタビュー全体の最後に入れる）

```
たろう：というわけで、今日は（組数）組目、（ゲスト名）さんにインタビューしてきました！（ゲスト名）さん、ありがとうございました！

（ゲスト名）：ありがとうございました！

たろう：この「Okayama Challengers Talk」、気に入っていただけたら、ぜひGOODボタンとチャンネル登録をお願いします！次は、（ゲスト名）さんからバトンを受け取った（次の組数）組目の方にお話を伺います。

この番組は、「岡山で一番あったかい」ボイストレーニング・ボーカル教室、Miyuki Musicの提供でお送りしました。

次回もお楽しみに！
```

## 運用ルール
- 冒頭は「お送りします」、クロージングは「お送りしました」と時制を変える（本人指示の通り）
- クロージングCTAは「GOODボタン」「チャンネル登録」「次回もお楽しみに」の3要素が必須（本人指示の核）。文言は毎回ゲスト名・組数に応じて差し替える
- 実績数字・成果保証などは入れない（キット共通ルールに準拠）
- 13組目より前（10〜12組目）の既存インタビューは遡及修正の対象外。今後の新規回から適用
