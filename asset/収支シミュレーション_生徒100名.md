# 収支シミュレーション：生徒100名達成時

ファネルデータ資産の育てポイント「神咲先生に生徒が定着し講師を増やせれば生徒100名も視野」を受け、実際に100名になった場合の収支を試算したもの。**すべて仮定に基づく試算であり、確定した数字ではない**（前提条件は随時更新）。

## タイムライン（2026-09-29・本人の見込み）

- 産休開始：**2年後**
- 最終形態（下記の講師配分）到達：**4〜5年後**
- 「このくらいの計算」との位置づけで、いずれも精緻な確定スケジュールではなく大まかな見込み

## 現状の実績値（試算のベース）

- 月商：50万円
- 在籍生徒数（アクティブ）：40名
  - アクティブの定義：定期コース契約中／回数券が有効期限内／その月に単発レッスン受講、のいずれか
- 逆算ARPU（1人あたり月間売上）：50万円 ÷ 40名 = **月12,500円**
- 主力プラン：月2回コース（全体の約6割）、ほか回数券・月3〜4回コースなど
- たろうさんの現在の月収：約20万円程度

## 講師体制の想定（100名・産休前の最終形態）

| 講師 | 担当生徒数 | 収入モデル |
|------|-----------|-----------|
| みゆき先生 | 20名（現状40名から自然減で減少） | 歩合なし。共同経営者としてのレベニューシェア（4割）のみ |
| 神咲先生 | 40名 | 歩合制（下記の段階表） |
| 新人講師（未採用・仮） | 40名 | 歩合制（神咲先生と同じ単価感） |

- 「みゆき20名・神咲40名・新人40名」は「みゆき先生の意図をくむなら、このくらいがちょうどいいかも」という本人の判断による配分（当初案の30/35/35から、みゆき先生の負担をさらに軽くする方向に修正）
- みゆき先生は「少しずつ現場を離れてほしい」という方針。既存生徒を他講師に引き継ぐのではなく、**卒業・離脱による自然減**で人数を減らしていく想定（無理な引き継ぎはしない）
- みゆき先生の収入は、自分がレッスンを担当する量に連動しない（歩合が発生しないため、現場を離れても収入源としての4割シェアは維持される設計）
- **産休を見越した計画**：みゆき先生の生徒は最終的にゼロにする計画。産休時はこの20名がゼロになり、総生徒数は一時的に約80名（神咲40名＋新人40名）に減る想定

## 講師拡大の実行順序（Notion「拡張ロードマップ」参照）

1. 神咲先生の生徒数を増やす
2. みゆき先生の生徒は自然減させる
3. 求人・教育への注力（新人講師の採用・育成はこの後）

## 歩合の段階制（2026年9月からの累計成約数ベース）

| 累計成約数 | 単価 |
|-----------|------|
| 〜9名 | ¥1,500／レッスン |
| 10名〜 | ¥1,600／レッスン |
| 20名〜 | ¥1,800／レッスン |
| 30名〜 | ¥2,000／レッスン |

※30名超の単価情報は未確認。本試算では2,000円が上限で以降変わらないと仮置き。新人講師も同じ単価感と仮定

## シミュレーション

**共通の前提**
- ARPU（月12,500円／人）は今後も変わらないと仮定
- レッスン頻度は主力プランに合わせ、平均月2回と仮定
- 固定費：月6万円程度（家賃半分・駐車場・決済ツール手数料）
- 広告費：月10万円（たろうさんが単独負担、レベニューシェアの対象外）
- レベニューシェア（みゆき先生4割・たろうさん6割）は、講師歩合・固定費を差し引いた後の金額に対して適用

**歩合コスト（100名時点。両講師とも累計成約30名超のため上限単価で計算）**
- 神咲先生：40名 × 月2回 × ¥2,000 = ¥160,000／月
- 新人講師：40名 × 月2回 × ¥2,000 = ¥160,000／月
- 合計：¥320,000／月

| | 現状（40名） | 100名時（20/40/40） |
|---|---|---|
| 月間売上 | ¥500,000 | ¥1,250,000 |
| 講師2名分の歩合（神咲40名＋新人40名） | ¥0 | −¥320,000 |
| 固定費 | −¥60,000 | −¥60,000 |
| 分配前の事業取り分 | ¥440,000 | ¥870,000 |
| みゆき先生 取り分（4割） | ¥176,000 | ¥348,000 |
| たろうさん 取り分（6割） | ¥264,000 | ¥522,000 |
| 広告費（たろう単独負担） | ¥0〜? | −¥100,000 |
| **たろうさん 手取り目安** | **約¥264,000**（実績の月収20万円と近い水準） | **約¥422,000** |

現状の試算値（約26万円）が実際の月収感（20万円程度）と近い水準になっており、モデルの前提としては大きく外れていないと考えられる。

## 産休シナリオ（100名達成後、みゆき先生ゼロ・一時80名）

- みゆき先生の20名は神咲先生・新人に引き継がれず、自然減でゼロになる（産休前と同じ考え方）
- 産休中は総生徒数が一時的に約80名（神咲先生40名＋新人40名）に減る
- 産休中、みゆき先生のレベニューシェアは**ゼロ**（たろうさんが分配前の事業取り分を100%受け取る）
- 生活費は産休中たろうさんが全額負担（みゆき先生の収入がゼロになる分、家計側の調整として本人が対応する想定）

| | 100名時（産休前） | 産休中（80名） |
|---|---|---|
| 月間売上 | ¥1,250,000 | ¥1,000,000 |
| 講師2名分の歩合（神咲40名＋新人40名） | −¥320,000 | −¥320,000（変わらず） |
| 固定費 | −¥60,000 | −¥60,000 |
| 分配前の事業取り分 | ¥870,000 | ¥620,000 |
| みゆき先生 取り分 | ¥348,000（4割） | ¥0（産休中はゼロ） |
| たろうさん 取り分 | ¥522,000（6割） | ¥620,000（100%） |
| 広告費（たろう単独負担） | −¥100,000 | −¥100,000 |
| **たろうさん 手取り目安** | **約¥422,000** | **約¥520,000** |

⚠️ **注目点**：この配分（20/40/40）だと、産休中のたろうさんの手取りは産休前（約42.2万円）より**増える**（約52万円）という結果になった。理由は、みゆき先生の生徒数が少ない分もともと彼女の売上寄与が小さく、レベニューシェアがゼロになったことによる「取り分比率アップ（6割→100%）」の効果の方が、生徒数減少（100→80名）による売上減の効果を上回るため。この結果が実態の感覚と合っているか、レベニューシェアの計算方法（分配前の事業取り分全体に対する割合という設計）自体がこの前提でよいか、本人に確認したい

## この試算の前提・不確実性（今後精度を上げるために確認したい点）

1. ARPU（月12,500円）は現状のコース構成比から逆算した数字で、コース単価改定や高単価コースへの誘導があれば変わる
2. 神咲先生・新人講師それぞれ40名という配分は想定であり、実際の生徒の流れ次第で変動する
3. 新人講師はまだ採用されていない（仮の前提）
4. 30名超の歩合単価は未確認（2,000円が上限で固定と仮置き）
5. 税金・会計費用など、事業運営に必要なその他経費は含めていない
6. みゆき先生の生徒が40名→20名に減るペース（自然減）は未確定
7. 産休開始（2年後）・最終形態到達（4〜5年後）はいずれも「このくらいの計算」という大まかな見込みで、確定スケジュールではない
8. 産休後にみゆき先生が現場に戻る計画があるのか、ゼロのまま完全に離れるのかは未確認
9. 産休中の手取りが産休前を上回るという試算結果（上記⚠️参照）が実態の意図と合っているか要確認
