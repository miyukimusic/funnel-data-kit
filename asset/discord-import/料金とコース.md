# 岡山本校 料金とコース

（出典: line / 経理 / 企画 / ホームページ / レッスン チャンネル）

## 料金の変遷

- 2024年10月〜: 新規入会者は「新料金」を適用（既存生徒は旧料金のまま据え置き）。
- 2025年2月分（2025年1月27日決済分）〜: 既存生徒にも新料金を統一適用すると決定し、LINEで案内（2024-12-20）。
- 2025年5月〜の新規生徒料金（2025-04-30 時点）:
- 入会金 5,500円
- 定期コース: 月2回 11,000円 / 月3回 13,500円 / 月4回 15,000円 / 月5回 18,000円 / 月6回 21,000円
- 回数券: 5回 30,000円 / 10回 50,000円
- 単発レッスン: 一般 7,500円 / 高校生以下 6,000円
- 2025年12月時点の料金（体験レッスン説明動画の台本より）:
- 定期コース: 月2回 11,000円 / 月3回 13,500円 / 月4回 16,000円 / 月5回 18,000円 / 月6回 21,000円（月4回と入会金が5月時点から変更されている）
- 回数券: 5回 30,000円 / 10回 50,000円（有効期限6か月）
- 入会金 10,000円（体験レッスン当日の申込で無料）

## 現行ポリシー（2025-12-11 説明動画台本より）

- レッスンは完全マンツーマン、1回45分。
- 定期コースは最低契約期間3か月。月1回コースは置かない（効果が出にくいため最低月2回から）。
- コースの回数変更は前月5日までに申請（決済処理が毎月10日頃に走るため）。回数を増やす場合はいつでも可（追加料金で即対応）。
- 返金は教室側に責任がある場合のみ。生徒都合の返金は不可だが、振替は可能。
- キャンセルは原則不可。当日欠席・無断キャンセルは受講済み扱い。振替は相談可。
- 体験レッスンは2回まで無料。1回目と2回目で別の講師を試すことも可。
- 予約は毎月15日までに翌月分のスケジュールを発表し、会員サイトから予約。

## その他のコース・商品

- プロコース（2025-01-01 新設）: 198,000円。最大12分割（月16,500円）可。月4回レッスン×12か月、年間カリキュラムをオーダーメイド。通常のボイトレに加え、音楽活動・情報発信・ブランディングのサポートと、Miyuki Music主催ライブへの出演権を含む。
- 短期レッスン: 45分×3回 15,000円。春・夏・秋・冬の季節ごとの短期レッスンとして設計（2025-01-01）。
- VIPコース: 2026年7月時点でモニター運用中。品質担保のため担当はみゆき先生のみ。
- 年パス: 2026-10-01 に料金ページへ追加（金額は投稿内に明記なし、要確認）。
