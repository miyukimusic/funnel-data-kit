# 講師の採用と教育

（出典: 教育・採用 / 横展開 / blog チャンネル）

## 採用の仕組み

- 選考フロー: 履歴書の提出 → 面接（1〜2回）→ 模擬レッスン（代表たろうのボーカルレッスンを実際にやってもらう）。
- 未経験者は育成前提で採用し、数か月間はみゆき先生のレッスンを受けてもらう。
- エントリーシート（2025-06-17 整備）: 氏名・連絡先など12項目で構成する応募フォームを講師募集の共通基盤として使用。
- 募集チャネル: エンゲージ、Indeed（無料版を1年間掲載し続け、良い人がいたら採用する長期目線）、タイミー、求人ボックスなど。チラシの作成・配布も実施。
- 面接時の課題: 新人ボイストレーナーに知っておいてほしい事項を伝え、回答＋練習方法を期限内に提出することを採用条件の1つにする運用（2025-10-24）。

## 採用基準の厳格化（2025-10-24 に方針決定）

- 「誰が聞いても上手い」ことを基準にする。
- 基準に達していない場合は、そのことを応募者に伝えたうえで反応を見る。仮採用でレッスンを始めて2か月後に再試験する形も可。
- 謙虚な人（生徒に対して上から目線でない人）を重視する。
- 拡大は目的ではなく手段なので、採用を焦らない。

## 指導観・講師としての心得（みゆき先生の考え方、2025-10-21）

- 生徒の前で歌う場は、講師が一番本気を出さなければならない場。生徒は講師の歌を冷静に聞いており、自分より下手な人から習いたいとは思わない。お金を払って来てくれる方の前で本気を出さないことは、歌のプロとして失礼にあたる。
- 生徒との個人的なLINE交換は原則しない。例外的に交換する場合も、レッスン以外でボイトレや音楽を教えることはしない（先生と生徒の関係を保てる相手に限る）。
- 講師へのフィードバックは、個人の好みに偏らないよう複数の視点（他の生徒や代表の意見）を確認してから伝える。

## 採用広報の素材

- マーケティングパートナー募集（2025-03-15）: オンラインレッスン展開のためのリスト獲得を担うパートナーを募集。最初は完全成果報酬（例: 1リスト獲得 3,000円／成約1件 7,000円というイメージ提示）、長期の場合は時給制への切替もあり得る形で提示。
- 講師募集文には教室の立ち上げストーリー（夫婦分業、生徒ゼロからのスタート、口コミで広がった経緯）を添える型を使っている（岡山本校のメディア実績と広報.md も参照）。
