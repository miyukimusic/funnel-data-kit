# 岡山本校 ポジショニングと差別化

（出典: blog / 企画 / instagram チャンネル）

## ポジショニングの核（2025-11-03 の壁打ちで言語化）

- 「本気系」ではなく「癒し・居場所系」が正解、という方向性を確認。
  - × プロ養成の厳しいレッスン / ○ 気軽に通える「心の居場所」
  - × スパルタで結果にコミット / ○ 楽しくおしゃべりしながら自然に上達
  - × 本気の人だけ / ○ どんな人でも受け入れてくれる温かさ
- コンセプト表現: 「岡山で一番ゆるいボイトレ教室」「岡山で最もゆるいボイトレ教室」。

## 他教室との違い（2025-12-03 ブログ記事「岡山ボイトレ教室リサーチ」より）

1. ゆるさ: マニュアルはあるがマニュアル通りにやらない。「レッスン」というより「おしゃべり会」。生徒の「今日はこれやりたい」に合わせてその場で内容を変える。
2. 隠れ家感: 住宅街の袋小路の奥にある一軒家。人目を気にせず通える。大きな看板なし。無料駐車場があり、車でそっと来てそっと帰れる。
3. 先生との距離感: いつも同じ先生が担当し、信頼関係を築ける。生徒の声として「月謝じゃなくて心のサプリ代」という表現がある。
4. 料金: 大手の相場（月3〜4回で15,000〜20,000円）と比べ、月2回11,000円からと抑えめ。設備に費用をかけていない分を料金に反映。
- 向いている人: ゆるく楽しく歌いたい人、厳しいレッスンが苦手な人、人目を気にせず通いたい人、カラオケで上手く歌えるようになりたい人。
- 向いていない人（記事内で明示）: プロ志望で本格的に学びたい人、駅近でないと通えない人、大手でないと不安な人。

## 地域性メモ（2025-11-25、岡山の県民性に関する壁打ちの要約）

- 岡山は保守的・慎重で、信頼できると判断してから動く人が多い。派手な営業や安さの前面訴求は逆効果になりやすい（「安かろう悪かろう」と疑われる）。
- 響くのは「実績」「信頼性」「地域での評判」。メディア出演実績は信頼の証明として有効。
- 値上げ時は「なぜこの価格なのか」の説明を丁寧にすることが重要（納得すれば適正価格を払う土地柄）。
