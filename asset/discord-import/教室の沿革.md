# 岡山本校の沿革

（出典: blog / line / 岡山本校 / レッスン チャンネル）

## 年表

- 2024年1月1日: Miyuki Music 開業。当初は大安寺の Studio Crescent を借りてレッスン（当時の呼称は「岡山大安寺校」）。
- 2024年: 1年間で体験レッスン受講者は76名（2024-12-31 の年始挨拶より）。
- 2025年1月: 開業1周年。体験レッスン累計90名に到達（2025-01-31 時点）。
  - 1月12日: Happy New Year Miyuki Music Fes!（エブリイOkanaka津高）
  - 1月19日: 1周年記念 Anniversary Party
- 2025年2月4日: リニューアルオープン。大元駅周辺の一軒家へ移転し「岡山大元校」へ。レッスンメニューを一新。
  - あわせて大人のピアノレッスンを開講（講師はみゆき先生。ボーカルと同じ料金体系で、月2回の内訳をボーカル/ピアノで組み合わせることも可）。
- 2025年2月: マスコットキャラクター名の生徒投票を実施し「おとちゃん」に決定。
- 2025年4月: 新講師くぜ先生が加入（くらしき作陽大学在学中、みゆき先生の後輩）。
- 2025年12月4日: 岡山本校の電話番号 086-238-8032 が開通（2025-11-22 時点で「仮確定」として共有、のち公式番号として定着）。
- その後、教室は岡山市北区神田町へ（現・岡山本校）。

## 運営メモ

- 移転期の時間割は13:00〜20:45（45分枠×8コマ）を基本形として設計（2024-12〜2025-03）。
- 旧HP（miyukimusic.net）は2025年1月1日にリニューアル運用開始。その後、自作ページ（miyuki-musiclesson.com）へ移行し、2025-12-08 に旧サイトはドメインだけ引き継いで解約する方針を決定（検索エンジンの評価は引き継げる前提）。
