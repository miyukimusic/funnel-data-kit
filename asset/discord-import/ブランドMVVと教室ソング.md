# ブランドMVVと教室ソング

（出典: 重要なお知らせ / オリジナルソング チャンネル）

## MVV（2026-07-11 に共有された正式文）

- Mission: 音楽を通して、人が自分らしく表現できる場所をつくる。音楽家や講師が、その才能によって生きていける機会を広げる。
- Vision: 日本に、音楽でつながる文化をつくる。
- Values: 表現 / 挑戦 / つながり / 音楽家への敬意 / 文化創造。
- Tagline: 「音楽でつながる、もうひとつの居場所。」
- 事業の構造: 入口＝音楽教室 → 関係＝コミュニティ → 交流＝イベント → 継続＝居場所 → 発展＝文化、という循環で設計する。

## 教室ソング（オリジナルソング）

- 「私の色で響くメロディー」（2025-04-28）: 教室ソング。歌詞にはブランド理念を反映させるポイントを明記して制作。
- 「音の向こうへ」: 2025-11-08 に歌詞を作成。2026-08-27 にはダイキ先生のバンドアレンジ版サンプルが制作された。
- 「TWIN STARS」: 夫婦デュオを題材にした楽曲。
- 制作には Suno（AI作曲）も活用（2025-12-04）。
