# オンラインレッスンと通信添削

（出典: オンライン / 岡山本校 チャンネル）

## オンラインレッスン

- リリース（2025-06-09）: Google Meet を使用。モニター価格は講師くぜ先生の例で、単発 5,000円 / 回数券 3回 9,900円・5回 15,000円・10回 25,000円。
- ハイブリッド形式の導入（2025-09-04）: ちほ先生のレッスンで、対面とオンラインを組み合わせる形式を開始。
- 運用変更（2025-12-12）: オンラインレッスンを教室で受講する形は廃止し、対面レッスンと時間が被ってもよい形に変更。
- 展開の試み（2025-02）: 福岡でのボイトレ講師募集など、オンライン前提のエリア展開を検討した記録あり（実現可否は未確認）。

## 通信添削

- 運用実績: 2025年2月頃から Skype 等を使った通信添削のやり取りが始まっている（レッスンチャンネルに実務記録）。
- テスト運用（2026-01-29）: 「本当に通信添削を使う人がいるか」を試す段階。利用が増えすぎた場合は受付停止か値上げで調整する方針メモあり。

## 通信添削プラットフォーム戦略（2025-12-02、検討中）

- フェーズ1（約3か月）: ココナラで実績づくり。価格はお試し 3,000円/1曲、サブスク 5,000〜6,000円を想定（ココナラの手数料は22%）。
- フェーズ2: MOSH と自社LPへ移行し、手数料負担と依存度を下げる。
- 位置づけ: 対面レッスンへつなぐ入口商品としての設計。
