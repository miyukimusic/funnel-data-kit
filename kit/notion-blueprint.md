# Notion雛形の構造定義（notion-blueprint.md）

## 建立の手順

1. **場所を顧客に選んでもらう**（確定ルール）: 「一枚は、Notionのどのページの下に建てますか？（迷ったら、新しく『AI集客』というページを作って、そこに建てます）」
2. 選ばれたページ（または新規「AI集客」ページ）の配下に、以下の2ページを作成する
3. 作成後、必ずURLを提示して「Notionを開くと、もう見えます」と伝える
4. progress.md に2ページのURLを記録する（以降の同期先）

## ページ1: 「◯◯さんの、ファネルデータ資産」（アイコン: 📄）

構造は `templates/ファネルデータ資産.md` と同一。Notion表現のルール:

- 冒頭に**完成証明callout**（🏆・初期状態は「完成の儀式で、ここに証明が刻まれます」とだけ書く）
- ブロック0＝テーブル（6行・「いまの状態」列は空欄）
- ブロック1〜6＝見出し1（`# ブロック1｜…`）、各設計資産＝見出し2（`## 設計資産1｜WHO — 理想のお客さま`）
- 各資産の記入項目＝箇条書き（テンプレと同一の項目名・初期値は空欄）
- 資産8・11・14＝テーブル（テンプレと同一の列構成）
- 末尾に「🌱 育てポイント」と「更新履歴」テーブル
- **余計な装飾・画像・カラムレイアウトは使わない**（崩れない・確実優先＝確定ルール）

## ページ2: 「拡張ロードマップ」（アイコン: 🗺️）

冒頭に1行: 「一枚が完成すると、ここに書いてあることが全部つながります。今日はやりません——完成してから、1つずつ。」

構造:

```
## いまの環境（ブロック0より）
（構築エージェントが setup-plan.md から転記: 入口・接点・出口（接点の回答からツール名が読み取れれば添える））

## つながる候補（あなたの環境から3つだけ）
（環境ヒアリングの結果から動的に3つ選ぶ＝確定ルール。例:
  Instagram運用者 → ①Instagram連携（投稿の下書きを一枚から自動生成）
                    ②LINE公式連携（配信文を一枚の言葉で量産）
                    ③計測の接続（追う数字を自動で集める）
 各1行の説明のみ。手順・ツール名の深掘りはしない）

他にも、メルマガ・広告・予約システムなど、あなたの環境に合わせてつながっていきます。

## つなぎ方
完成した一枚と一緒に、伴走AIに「ロードマップの続きをやりたい」と言ってください。
```

**禁止**: AX・バンプ・価格・商品名への言及はゼロ（確定ルール）。連携候補は「機能の1行説明」まで——売り込み・営業文にしない。

## 同期のルール（伴走AIエージェント用）

- 同期タイミング: **ブロック完成ごと**（毎問ごとには同期しない——会話のリズム優先）
- 同期方法: ローカル `asset/ファネルデータ資産.md` の該当ブロックを、Notionページ1の同名セクションへ**上書き転写**（構造は変えない・埋まった項目だけ更新）
- 同期後に必ず言う: 「いま、Notionを開いてみてください。ブロック◯が埋まっています」
- **同期に失敗したら**: 顧客には告げずローカル継続し、progress.md の「Notion同期」欄に未同期ブロックを記録。次のブロック完成時にまとめてリトライ。2回連続で失敗したら「Notionへの反映は最後にまとめて行いますね」と一言だけ伝える
- 完成の儀式（第3幕）: 全ブロックを最終同期→完成証明calloutを記入（完成日時・宣言文・作れるものリスト・シェア文1行）
